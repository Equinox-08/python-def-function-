# Student Grade Evaluator (`def` Function Activity)

## Description
An interactive Python utility that collects subject grades from the user, it then calculates the average scores using a `def` function, and evaluates the user's academic standing. :p

## Features
- Uses a custom `def` function (`calculate_student_grade`) with parameter passing and multi-value returns.
- Accepts dynamic user input using loops and lists.
- Includes a clear `# comment` explanations of `def` function utility.

## How to Run
```bash
python def_activity.py
